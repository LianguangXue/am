# am 看板与 Delegate 子任务（0.5）

启动已有 store 的 `am serve` 后打开它打印的网址。左侧 **Delegate 子任务**，或网址末尾
的 `/#delegate`，进入子任务工作台。升级时只重启既有看板服务并刷新浏览器；不要
`am init --force`，不要删除 store 或重新导入所有对话。

## 查看与筛选

- 概览展示活动会话、任务、工作流和最近子任务。
- 子任务工作台支持全部／活动／需关注／执行完成筛选、后端选择和搜索模型、角色、
  工作项、任务 ID、主会话 ID。初次显示 24 项，可继续加载。
- 子任务卡片显示后端、model、effort、执行状态、阶段、等待、心跳、已观测 tokens、
  最近事件、异常摘要，以及结果读取／验收／对话归档状态。
- 点击主会话回到其详情，查看属于这个会话的子任务。匹配使用完整 ID；Codex／DSH
  原生宿主另匹配已知的逻辑 session hash，不凭八位短 ID 猜测关系。无法匹配时明确标注。
- 展开详情后，自动刷新保留展开状态。支持复制任务与主会话 ID。刷新按钮可立即刷新，
  暂停按钮停止定时请求，切回页面会更新快照。移动端自动切为单列。

查看进展不必绑定 am task。原有 `delegate_handoff` 导入仍用于明确的任务交接，不会因
看板展示而自动创建 am task、抢占租约、验收任务或恢复已归档的对话。

## 数据含义

状态来自 delegate 的任务记录，心跳／进程身份只是点时观测，不是工作质量或完成百分比。
不同宿主的记录不能从本机核验进程时显示未观测，而不会断言它已经死亡。

“执行完成”与“已验收”分别显示。已归档不等于记录被删除。tokens 是当前执行可取得的
usage：Codex 使用本次 delta，避免把恢复前的历史用量算进去；缺数据显示未提供，
不会当零，也不等于剩余额度、实际费用或跨供应商等价额度。

界面只读，不会启动、恢复、取消子任务或调用账号／额度接口。需要续接时，仍由所属
主会话按原有授权规则执行。看板不会自动清理失败任务、进程或用户工作目录。

## 数据源、范围与性能

数据源依次取 store config 的 `delegate_state_dir`、环境 `DELEGATE_STATE_DIR`，最后为
`~/.claude/delegate`。界面显示解析后的实际路径。自定义安装可在已有 config 中指定这个
字段；不需要导入或复制原始对话。多个会话共享同一 delegate store 即可集中观察。

读取优先使用 `active.json`（最多 64 个候选），再使用 `task-index.json` 最近 40 个任务，
合计最多读取 100 个去重任务记录。任务与父任务、主会话的归属必须一致。页面标明范围、
截断和读取错误；不是所有历史任务的完整清单。只读取已知索引路径，不递归扫描 home
或所有 transcript；单个文件最多 2 MB，拒绝符号链接记录和 FIFO。

`/api/delegate` 独立于会话快照的构建锁，约每 2.5 秒请求一次；源快照缓存 2 秒，并复用
未变化的 JSON。会话快照约每 10 秒请求一次。首屏并行获取两者，不必等会话历史完成。
前端不会重叠发出同类刷新请求，后台标签页暂停轮询，导航内容未变时不重建 DOM。
HTML／JSON 对支持的客户端使用 gzip，避免重复传输大量原始文本。

模型调用次数为零；这些操作仍占用少量本机 CPU、内存、文件读取和 HTTP 传输资源。
看板不展示完整任务 prompt、完整结果或原始日志，只投影状态元数据和受限诊断摘要。

## 验证

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -q
bash tests/smoke.sh
node tests/clipboard.js
```

可选浏览器回归需自行提供 Playwright 与 Chromium，不是 am 的运行依赖：

```sh
AM_PLAYWRIGHT_MODULE=/path/to/playwright \
AM_UI_ARTIFACT_DIR=/tmp/am-ui \
node tests/dashboard_browser.cjs
```

该回归拦截全部请求，使用本地 fixture 验证慢会话接口不阻塞子任务首屏、筛选／搜索、
父会话跳转、独立状态更新、展开状态、输出转义、暂停恢复及移动端布局，不修改真实任务。
